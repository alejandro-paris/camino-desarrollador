# El Camino del Desarrollador

Este es un juego parodia sobre el desarrollo de "Tu primer feature". Fue creado para una competición de videojuegos con la temática "Conecta 3" desarrollada con Google AI Studio a modo de pruba de concepto

## ¿De qué trata?

En este juego, los jugadores asumen el rol de un desarrollador que debe completar su primera funcionalidad en un entorno lleno de desafíos y obstáculos. El objetivo es conectar tres elementos clave del desarrollo, mientras se enfrentan a mejoras, bugs y revisiones de código.

## Instrucciones para ejecutar el proyecto

**Requisitos previos:** Node.js

1. Clona este repositorio:
   ```bash
   git clone https://github.com/alejandro-paris/camino-desarrollador
   ```

2. Navega al directorio del proyecto:
   ```bash
   cd el-camino-del-desarrollador
   ```

3. Instala las dependencias:
   ```bash
   npm install
   ```

4. Ejecuta la aplicación:
   ```bash
   npm run dev
   ```
